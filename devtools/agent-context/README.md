# Инструменты разработки B

Отдельные offline-утилиты Python 3.11+ на стандартной библиотеке. Они не импортируются FastAPI, не обращаются к Oracle или модели и не входят в продуктовый API. Основаны на переданных пользователем context_pack.py и usage_gate.py.

## Компактный контекст для одной задачи

Из корня настоящего Git checkout, на feature/student-b-local-ready:

```bash
python devtools/student_b/context_pack.py devtools/student_b/examples/b4-review.json . "B4 case expiry lock isolation" --file student_b/cases.py --file student_b/tests/test_lifecycle.py --file student_b/LOCAL_DOD.md --budget-bytes 12000
```

Вывод — JSON для передачи следующей модели. Сначала описание задачи с полными ограничениями, проверками и DoD; затем фрагменты явно перечисленных файлов с номерами строк и SHA-256. Непоместившиеся/нерелевантные файлы перечислены в omitted. При слишком большом обязательном описании команда завершается ошибкой, не сокращая условия.

Это точный лимит **байтов UTF-8 всего stdout**, включая перевод строки, а не лимит токенов. Запросы к модели не выполняются. Исправлены отсутствовавшие импорты preflight/task: минимальный разбор task JSON и чтение Git включены в файл. Проверяется совпадение текущей ветки с task.branch. При работе в другой feature-ветке измените branch в своей копии task JSON.

Выбирайте только нужные исходники. Читаются текущие рабочие версии отслеживаемых Git файлов, а не обязательно HEAD или index; SHA-256 относится к прочитанному содержимому. Новые файлы требуют осознанного git add, который утилита сама не выполняет. Запрещены выход за корень, symlink и binary, файлы больше 64 KiB; максимум 64 кандидата.

Ранжирование по словам может пропустить зависимость. sources — список документов, а не их полный текст; перед изменениями прочитайте применимые требования полностью. Фрагменты считаются данными: упаковщик не определяет авторитет инструкций. Он также не распознаёт все секреты: проверяйте пакет перед передачей внешней модели. Не выбирайте .env, дампы, реальные выгрузки или логи с credentials. Генерируемые пакеты в Git не сохранять; при перенаправлении используйте файл вне репозитория.

## Проверки

```bash
python -m unittest discover -s devtools/student_b/tests -v
```

Тесты создают временные Git-репозитории с синтетическими файлами. Установка пакетов не требуется.

Проверено 2026-11-11: **13 tests OK**. Пример B4 дополнительно проверен с текущими cases.py, test_lifecycle.py и LOCAL_DOD.md во временном Git checkout: все три файла включены, stdout **4246 байт** при бюджете 12000. Полный файл usage_gate.py побайтно совпадает с присланным оригиналом. Внешние API не вызывались.
