# MAGNA TRACE — Додаткові архітектурні нотатки

**Статус:** додаткові пояснення до затвердженої базової документації команди. Канонічні правила визначають `docs/product.md` та `docs/architecture.md`; рішення з обґрунтуванням записані в `docs/decisions.md`.

- Межі `"1"` і `"1.0"` рівні після розбору через `Decimal`. Перевіряємо назву вимірювання, ключі, одиниці, значення, зміст тесту й контекст виробу. Якщо обов’язкова перевірка не проходить, повертаємо `NOT_COMPARABLE` і конкретну причину.
- Для `same_station_across_serials` фіксуємо станцію й рахуємо різні серійні номери. Для `same_serial_across_stations` фіксуємо серійний номер і рахуємо різні станції. Одна сутність недостатня; дві дають допустиме порівняння з `LOW_SAMPLE`; від трьох попередження зникає. Повторні записи впливають лише на кількість рядків. Висновок про фізичну причину з цього не випливає.
- У P0 справи зберігаються в оперативній пам’яті. Для неіснуючого, простроченого або втраченого після перезапуску ID компонент B повертає один код `CASE_NOT_FOUND_OR_EXPIRED`.
